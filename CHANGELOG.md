## 2.1.1 - 2026-09-08

- Fix Edge toolbar popup shaking, collapsed width and clipped controls. Establish a 368-pixel intrinsic width before first layout, remove the loading-width switch, and remove height-dependent layouts that feed back into browser popup sizing.

To update an unpacked installation, replace files in its existing folder and use **Reload** on its card at `edge://extensions`. Keep the same folder and extension registration to retain settings. Removing the extension deletes its storage; export settings first if moving to a new registration.

## 2.1.0 - 2026-09-08

- Verify installed static rulesets and owned dynamic rules before reporting active network protection. Report degraded or unavailable status when verification fails. This verifies configuration, not every page's blocking coverage.
- Show when protection is paused on the current site and label page counts as hidden elements.
- Restrict learned-host rules to Strict mode; switching to Balanced or Relaxed removes those rules while retaining local evidence for later reuse.
- Default local learning off on new installations and ignore incognito learning signals. Preserve existing saved choices. Other extension statistics are not redesigned for incognito isolation in this release.
- Restore version-1 JSON settings backups into a reviewable form. Reject invalid types, selectors, unknown fields and oversized files; save explicitly to apply.
- Preserve commas inside CSS selectors such as `:is(.ad, .promo)` and quoted attribute values.
- Prepare support diagnostics locally without URLs, hostnames, selectors, page content or browsing counters.
- Carry forward release stylesheet packaging, inherited exception and statistics reset fixes from the working 2.0.1 baseline.

### Upgrade

Install the 2.1.0 package or reload the unpacked extension, then reload open pages. Existing protection levels and site exceptions remain saved. If learning was previously enabled, it remains enabled in Strict mode; turn it off or reset learned hosts from Settings if desired. No new permissions or remote services are added.

### Scope

No claim of improved field blocking rate, anonymity, market share or competitor superiority follows from these changes. Regional subscriptions, finer per-site protection levels and broader interactive compatibility testing remain future work.
